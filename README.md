# 💰 Harcama Takip Sistemi

Python ile geliştirilmiş, kullanıcıların günlük harcamalarını konsol üzerinden kolayca yönetebilmelerini sağlayan bir bütçe takip uygulamasıdır.

## 🚀 Özellikler

- **Harcama Ekleme:** Başlık, kategori ve tutar belirterek yeni harcamalar ekleyebilirsiniz.
- **Harcamaları Listeleme:** Kayıtlı tüm harcamalarınızı ve toplam bütçe durumunuzu görüntüleyebilirsiniz.
- **Harcama Düzenleme:** Mevcut harcamalarınızın detaylarını (başlık, kategori, tutar) güncelleyebilirsiniz.
- **Harcama Silme:** Hatalı veya eski kayıtları sistemden silebilirsiniz.
- **Kalıcı Veri Kaydı (JSON):** Tüm verileriniz `harcamalar.json` dosyasına kaydedilir. Programı kapatsanız bile verileriniz asla kaybolmaz.
- **Hata Yakalama (Try-Except):** Kullanıcı hatalarına karşı programın çökmesini engelleyen güvenlik önlemleri mevcuttur.

## 🛠️ Kullanılan Teknolojiler

- Python 3.x
- JSON (Yerleşik Kütüphane)
- Git & GitHub (Versiyon Kontrolü)
